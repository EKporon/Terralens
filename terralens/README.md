# TerraLens 🌍

## Know the Land Before You Buy It

TerraLens is a land intelligence platform that helps users evaluate land before purchase or development.

By entering an address or GPS coordinates, users receive environmental and geographical insights including:

- Interactive map visualization
- Weather information
- Elevation data
- Location analysis
- Land suitability summary

---

# Problem

Buying land is a major investment, but many buyers lack access to important information about the terrain, climate, and environmental conditions surrounding a property.

TerraLens aims to provide accessible data-driven insights to help users make better land-use decisions.

---

# Features (MVP)

✅ Search land by address  
✅ Search using GPS coordinates  
✅ Interactive map  
✅ Current weather information  
✅ Elevation analysis  
✅ Land intelligence summary
